# Discord Bot 🤖

A simple Discord bot project created while exploring how to build and work with Discord bots.

## 🎯 Purpose

This project is mainly for learning and experimenting with:

* Discord bot development
* Discord API
* Bot commands and interactions
* Events and message handling
* Integrating different features into a Discord bot

## 🛠️ Tech Stack

* **Language:** JavaScript
* **Runtime:** Node.js
* **Platform:** Discord

## 🚀 Getting Started

Clone the repository and install the dependencies:

```bash
git clone https://github.com/mwanzia-simon/DISCORD-BOT.git
cd DISCORD-BOT
npm install
```

Create a `.env` file and add your Discord bot credentials:

```env
DISCORD_TOKEN=your_bot_token
```

Then start the bot:

```bash
npm run dev
```
